🐛 TROUBLESHOOTING
──────────────────
Problem: Services won't start
Solution: Check logs with "docker-compose logs <service>"

Problem: Port already in use
Solution: Change port in docker-compose.yml or kill process using port

Problem: Can't reach services
Solution: Verify networks with "docker network ls" and "docker network inspect"

Problem: Database connection errors
Solution: Check DATABASE_URL in .env matches docker-compose setup

Problem: Out of memory
Solution: Increase Docker memory limit in Docker Desktop settings
